# BF Tech Lab — website demos

Demo websites for prospective clients. The businesses, people and reviews are fictional.

| Demo | Path |
| --- | --- |
| Brookside Family Dental (dental practice, online appointment requests) | `dental/` |
| Ridgeline Auto Sales (used car dealer, inventory + demo admin) | `dealer/` |

Each demo is a single HTML file (Tailwind CDN + GSAP, no build step), published with GitHub Pages from the `main` branch.
