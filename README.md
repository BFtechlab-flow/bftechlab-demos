# BF Tech Lab — website demos

Demo websites for prospective clients. The businesses, people and reviews are fictional; photos are stock images from Unsplash.

| Demo | Path |
| --- | --- |
| BF Dental (dental practice, online appointment requests) | `dental/` |
| BF Motors (used car dealer, inventory + demo admin) | `dealer/` |

Each demo is a single HTML file (Tailwind CDN + GSAP, no build step), published with GitHub Pages from the `main` branch.
